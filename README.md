# Lab 3 – Feedforward Neural Networks with PyTorch

## Overview
This lab implements a Feedforward Neural Network (MLP) using PyTorch to classify obesity levels. The project covers building the network, training and validation, hyperparameter tuning, and evaluating the final model.

## Objectives
- Design a feedforward neural network.
- Train the model using PyTorch.
- Experiment with different network architectures and hyperparameters.
- Evaluate the model using accuracy, macro F1-score, and a confusion matrix.
- Compare the neural network with a classical machine learning model from Lab 2.

## Technologies Used
- Python
- PyTorch
- NumPy
- scikit-learn
- Matplotlib
- Jupyter Notebook

## Files
- `Lab_3.ipynb` – Main notebook containing all implementations and answers.
- `requirements.txt`


## Results
- **Test Accuracy:** 91.25%
- **Macro F1 Score:** 0.9079

## Key Experiments
- Compared different hidden layer sizes.
- Tuned the learning rate.
- Tested the effect of dropout.
- Selected the best-performing model based on validation accuracy.
